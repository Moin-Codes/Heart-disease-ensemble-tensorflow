# Heart Disease Classification Using TensorFlow and Ensemble Techniques

## 📌 Project Overview

This project focuses on predicting the presence of heart disease using the **Heart Disease UCI dataset**. A classification model is developed using **TensorFlow/Keras**, and ensemble learning techniques are used to improve the reliability and performance of the prediction model.

## 🎯 Objective

The main objective of this project is to build a machine learning classification model that can predict whether a patient is likely to have heart disease based on various medical features.

## 📊 Dataset

The project uses the **Heart Disease UCI dataset**, which contains patient-related medical attributes used to predict heart disease.

## 🛠️ Technologies Used

* Python
* TensorFlow
* Keras
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Google Colab

## 🤖 Model

A neural-network-based classification model was developed using TensorFlow/Keras. Ensemble techniques were used to combine multiple model predictions and improve classification performance.

## 📈 Model Evaluation

The model was evaluated using **accuracy, precision, recall, F1-score, and a confusion matrix**. The results indicate that the model was able to effectively classify patients into heart disease and no-heart-disease categories.

## 🔍 Key Steps

1. Loaded the Heart Disease UCI dataset.
2. Performed data preprocessing.
3. Prepared the features and target variable.
4. Split the dataset into training and testing sets.
5. Built the classification model using TensorFlow/Keras.
6. Applied ensemble learning techniques.
7. Trained the model on the training data.
8. Evaluated the model using standard classification metrics.

## ✅ Conclusion

The project demonstrates how **TensorFlow and ensemble learning techniques** can be used for heart disease classification. The developed model provides useful predictive performance and demonstrates the application of machine learning techniques to healthcare-related datasets.
